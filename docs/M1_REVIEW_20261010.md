## 结论

M1-06–09 的代码、全量回归与隔离 Electron 验收通过；M1-05/10 完整实机验收未通过。不是整个 M1 完成，M0/M2/发行门禁不变。

## 已检查的关键不变量

- 配置字段由服务端规范化，数字有范围，枚举有白名单，未知键被丢弃。反馈 revision 不写入用户配置，load/set 递增进程内版本；条件写在同一持久化队列检查，磁盘成功才更新内存版本。
- 普通配置不能伪造列表/库路径。WE JSON 只匹配 inventory，不读输入路径、不执行脚本。Origin、loopback token、数量/文本/512 KiB 上限沿用服务端保护；UI 文本使用 textContent。
- 轮播只有一个服务端调度器；filesystem await 和选择/回滚都重查用户状态，CAS 冲突不把候选误标失败。失败反馈只处理当前轮播候选；重复/过期/ABA 被拒绝。
- 工作台保存队列与文件读取 busy 参与桌面握手；poll single-flight，用户保存/手选优先。预览失败不改变显示选择标签，服务端回退/跳过被验证。
- prepare 持有旧帧，ready 后 commit；并发结果按 revision 作废。过场仅用 WAAPI 的 opacity/translate/scale/clipPath，不覆盖取景 transform；动画中断/restore 最多两槽位，旧媒体静音后退休并释放。
- 减动态效果尊重系统和显式选择；硬切没有隐含 CSS 淡化。视频暂停/隐藏政策与预加载首帧相容。大媒体仍走 Range，配置库索引/列表不注入 CDP，49234-byte bootstrap 和 apply 上限测试通过。

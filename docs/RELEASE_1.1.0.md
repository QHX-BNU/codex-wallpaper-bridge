# Codex Wallpaper Desktop 1.1.0

2026-10-16 正式版，Windows x64 单文件 Portable EXE。

本版基于上次 GitHub 提交 `54ed3b0`（`v1.0.0`）之后的修改，仍以 M3 功能为基线，增加兼容修复与工作台顶栏改进。没有恢复 M4 分区玻璃主题、字体/光标、壁纸配色联动、头像/桌宠或多语言功能。

## 从 1.0.0 到本版的修改

### 1. 修复首次注入视频失败

- 解决第一次应用视频时只有 Codex 主题改变、壁纸未成功显示的问题。
- 原先仅覆盖直接渲染 Scene 的首文档媒体 CSP 初始化，现在同时覆盖普通图片和视频；初始化状态在首次接入、设置更新和页面重建之间正确传递。
- 应用和回退均等待真实媒体就绪，不再把仅创建 DOM、仍在加载、播放被拒绝或切换失败当作成功。
- 普通媒体 CDP 应用等待预算设为 20 秒，为原有 15 秒媒体加载检查预留失败回报和候选资源清理时间；并未扩大媒体本身的加载时限。

### 2. 改进 Codex 透明兼容，修复长聊天黑底

- 补齐项目/设备工具栏、空间标题/搜索区、插件/共享页面 sticky 页头和输入框内层底色的兼容规则。
- 清理聊天底部渐变装饰板，修复已有长聊天底部再次出现黑底的问题。
- 对 `data-thread-scroll-footer` 使用精确语义规则，不通过扩大 3,000 节点自适应扫描上限解决问题。
- 保留按钮、代码编辑器、附件、菜单和弹窗的正常背景与交互，不采用全局透明覆盖。
- 基础透明兼容内部版本更新为 `0.1.4`。

### 3. 修复系统音乐设置自动关闭

- 完整和轻量播放列表响应均返回媒体偏好，避免每 1,500 毫秒的轮询把本地选项覆盖成缺失值。
- 前端只合并明确提供的已知布尔设置；缺字段、部分字段或异常响应不会清空既有选择。
- 保留设置保存版本号和竞态保护，不让较旧响应覆盖较新的操作。

### 4. 修复重复保存/应用时报 500

- 解决当前壁纸直接复用时，被再次标记为 `loading` 却不再触发提交回调的问题。
- 只有切换到新媒体或强制重载时才进入加载态；复用已提交媒体时保留其真实状态。
- 按切换器当前实际媒体标识判断是否复用；媒体槽已清理时仍会重新加载。
- 保留真实解码/播放错误检查，不通过强行写入 `ready` 掩盖失败。
- 注入运行时内部版本更新为 `0.6.0-m3-media-policy-v4`，与桌面产品版本独立。

### 5. 工作台融合顶栏

- Windows 工作台使用 40 DIP 高度的融合标题区，底色、文字及原生窗口按钮随深浅主题同步。
- 顶栏显示 `Wallpaper Bridge` 和基于工作台握手的本地服务连接状态；该状态不代表已连接 Codex 或壁纸注入成功。
- 保留 Windows 原生最小化、最大化和关闭按钮、窗口框架与贴靠入口，以及原有最小化/关闭到托盘的行为。
- 只允许标题区域拖动，工作台内容不受拖动区域覆盖，并避让原生窗口按钮。
- 新增 IPC 只接受固定深浅主题枚举，沿用可信桌面页面来源校验，不暴露通用窗口控制接口。

### 6. 回归测试与发布整理

- 新增透明兼容、首次媒体注入、媒体复用、系统音乐设置和融合顶栏五组回归测试。
- 补充独立 Electron 首次媒体/顶栏验证脚本与兼容层夹具，增强连续复用应用结果断言。
- 同步 override 与 runtime 三组注入模块，更新既有媒体与桌面主流程测试。
- 桌面产品与锁文件项目版本统一为 `1.1.0`；依赖版本保持不变。
- EXE、测试产物和本机工作记录不提交到源码仓库，成品继续通过 Release 附件分发。

## 已知限制与后续验证

- 本版修复的是上述具体路径，不代表所有保存/应用失败原因都已消除。HTTP、保存握手和 Scene 就绪等待预算仍需统一；配置已落盘但宿主应用失败时的提示仍有改进空间。
- 桌面 `settings.json` 仍采用直接覆盖写入，原子保存改进尚未纳入本版。
- 网易云实际曲目读取、真实 ffmpeg 转码、长时间内存/资源占用和 Store/本地 EXE 双宿主完整生命周期回归尚未闭环。
- 融合顶栏已验证布局、主题切换和原生窗口区域命中；尚未实际触发物理拖动、双击标题栏和 Snap 弹出菜单。
- 其余平台、Scene/Web 兼容性和硬件设备切换边界继续适用，见 [README 限制说明](../README.md#目前的限制)。

## 升级与回退

1. 退出旧工作台（包括托盘进程），下载本版 EXE 并核对校验文件后启动；无需替换 Codex 的安装文件。
2. 源码用户拉取本版后按 README 构建或运行。个人配置与媒体素材不随发布上传，也不需要删除。
3. 如需回退，先退出新工作台，再使用 [1.0.0 Release](https://github.com/whisperia6/codex-wallpaper-bridge/releases/tag/v1.0.0) 的原版 EXE。保留个人配置备份，不覆盖已有标签或 Release。
4. 遇到问题可从托盘查看日志，重点核对媒体就绪/播放错误、工作台连接状态和实际壁纸显示；反馈时去除账号信息、聊天内容、会话令牌及个人路径。

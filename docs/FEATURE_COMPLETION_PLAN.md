## 5. 统一实现约束与架构决策

1. 大视频只走现有 token-scoped loopback Range。CDP 保持 bootstrap <100 KiB、apply <10 KiB；大型引擎脚本走受控媒体源，不嵌进 CDP。注入 ready 与实际首帧分别报告。
2. `bridge-overrides` 存在的同名文件是修改源，包含 `public/electron-host.js`，不只限于 `src`；同步后的 `bridge-runtime` 必须一致。未被覆盖的 scanner/config-store/media-server/asset-library/library-policy/app/styles 直接修改 runtime。dist 只通过构建生成，out 保存构建与验证证据。
3. 单配置真源：服务端 schema/默认值/迁移，UI 不另造一套归一化规则；任何新增字段必须端到端贯通。
4. 统一 prepare/commit/cancel 与状态机，不为轮播/手选/抽屉各建独立媒体播放器。选择保留旧画面而非先清空；接受短时双层内存开销，必须有上限和释放。
5. 引擎优先复用锁定 MIT 组件，不自行从零重写 WE 引擎；代价是上游兼容性需样本验证。撤销条件是隔离/资源/目标 Chromium 无法通过 PoC；此时保持该项未完成并报告技术原因，不把静态图作为替代完成。
6. 第三方 HTML/属性/立绘/预设/二进制均属外部输入：文件白名单、路径 containment、大小/类型/范围限制、HTML 沙箱、origin/source 消息校验、下载哈希、日志脱敏。
7. 转码/导入/目录迁移必须有任务状态、进度、取消、失败明细与恢复方式；不以一个长时间阻塞的 HTTP 请求承担全流程。
8. 保留关闭到托盘/完全退出的当前行为；任何改变退出语义必须单独列变更，不能静默关闭 Codex 或强制还原。
9. 本阶段联动 TDD 与代码审查：持久化/网络/跨模块均要求正向+失败+恢复测试，再由主 Agent 复核子任务和完整构建。
